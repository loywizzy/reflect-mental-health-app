# 🎨 Wireframes — Reflect Mental Health AI Web App

เอกสารนี้แสดง wireframe ของหน้าหลักใน MVP

---

## 📱 Page Overview

| หน้า | จุดประสงค์ |
|------|----------|
| Home | Landing page + แนะนำแอป |
| Journal | เขียน/พิมพ์บันทึกความรู้สึก |
| Insight Dashboard | แสดงแนวโน้ม + Trigger Map + AI Reflection |
| Profile | ตั้งค่า persona + จัดการข้อมูล |

## 🎨 Design Notes

### Color Palette (Calm & Accessible)
- **Primary**: Soft Sage Green `#8FBC8F`
- **Secondary**: Warm Beige `#F5F5DC`
- **Background**: Off-white `#FAFAFA`
- **Text**: Soft Charcoal `#4A4A4A`
- **Accent**: Muted Lavender `#E6E6FA`

### Typography
- **Headings**: Inter (Google Fonts)
- **Body**: Noto Sans Thai

### UI Principles
- ❌ No aggressive colors (red warning)
- ❌ No harsh borders
- ✅ Rounded corners
- ✅ Soft shadows
- ✅ Generous whitespace
- ✅ Calming micro-animations
